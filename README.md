# 🎨 Animated Thumbnail & Poster Portfolio

A modern cinematic portfolio website for thumbnail and poster designers built with Next.js, GSAP, TypeScript, and Tailwind CSS.

Designed with smooth animations, immersive layouts, fullscreen previews, and responsive UI for showcasing creative visual work professionally.

---

## ✨ Features

- 🎬 Smooth GSAP animations
- 📱 Fully responsive design
- 🖼️ Thumbnail & poster showcase
- 🔍 Fullscreen image preview modal
- ⚡ Optimized Next.js performance
- 🎨 Modern cinematic UI
- 🌙 Clean glassmorphism effects
- 📂 Animated project gallery
- 🍔 Mobile navigation menu
- 🚀 Ready for deployment

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Thumbnail_-Poster_Portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

---

## 📦 Production Build

```bash
npm run build
```
